## 🎬 BookMyShow Replica
My first web project — a replica of BookMyShow, built to learn how real-world booking apps work.
🔗 Live Demo: bookmyshow-replica.lovable.app

# 👋 Why I Built This
I wanted to build something I actually use in real life, and BookMyShow felt like a perfect challenge. The goal was to understand how a real-world booking app works — the layout, the page flow, and how everything connects from browsing a movie to selecting a seat.

# 🛠️ How I Built It
I built this using Lovable, an AI-powered web app builder. Since I'm just starting out, I described what I wanted each page to look like and do, and iterated from there. Even though Lovable generated the code, reading through it helped me understand React concepts like components, routing, and state.
Tech used:

- React — component-based UI
- Tailwind CSS — styling
- shadcn/ui — UI components
- React Router — page navigation
- Vite — build tool


# 🧩 What I Built

- Home page with movie listings
- Movie detail page with cast & info
- Show & date selection
- Interactive seat map
- Booking summary screen


# 📚 What I Learned

- Thinking in components — breaking a big UI into smaller reusable pieces
- User flow design — home → movie → date → seats → confirm
- Iteration is normal — the first version looked nothing like the final one
- How to read and understand generated React/JSX code
